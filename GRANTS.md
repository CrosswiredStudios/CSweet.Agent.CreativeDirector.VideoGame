# Video Game Creative Director grants

The reviewed authority source is `csweet-plugin.json` for agent version `1.2.4`.

- Business, finance, organization, roster, and approved memory reads ground creative decisions.
- User-memory proposals are limited to explicit interaction, involvement, story-participation, and approval preferences.
- Business-memory proposals are limited to explicit project decisions and sanitized attachment metadata/digests; raw content and private paths are never stored.
- Onboarding completion acknowledges `com.csweet.agent.onboarded.v1` only after the proactive calibration message and durable state write.
- Resource-change authority proposes exactly one Product Manager reporting to the Creative Director. It does not approve, source, install, spend, or hire.
- Communication and coordination grants support manager onboarding, milestone notices, exact-digest PM handoff, and reporting-tree creative questions.
- Operating-state grants preserve lifecycle, manager preferences, supporting message IDs, references, staffing lineage, and notification idempotency.
- Personal-work grants let the installation read and execute only its own durable Creative Director agenda. The SDK privately owns claims and completion transitions; the agent may requeue its own waiting or blocked card when a correlated chat answer arrives.

Hiring, spending, candidate selection, installation, and later delivery-team roles remain governed by separate platform approval flows.
