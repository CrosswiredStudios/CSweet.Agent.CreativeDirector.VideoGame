# 2.1.7

Require a dedicated project identity inference step before creating a new project proposal. Infer
the actual game name and a player-facing marketing blurb from the exact accepted creative vision,
instead of copying a document heading such as “RESONANCE — Game Pitch” or using a generic delivery
description. Lead the blurb with the hook, gameplay and appeal while preserving accepted scope.

Validate bounded plain-text fields, allow one correction, and persist the evidence-bound identity
before Producer coordination. Duplicate wakes and interrupted handoffs reuse the saved result.
Invalid output blocks proposal creation; a corrected model configuration can retry. Existing
proposals and approved projects keep their current identity.

Producer 4.0.8 preserves the inferred fields while preparing delivery planning. Upgrade both agents
through published releases and the Installed Agents update flow. No new capabilities or grants.
