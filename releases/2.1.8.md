# 2.1.8

Fix project setup and Producer documentation handoff failing with “stateKey is too long.”
Project identity inference now uses SDK 5.3.0's bounded key builder for its accepted result and
provider/model-specific attempt cache. Existing accepted identities retain their exact keys;
changing the model can retry failed inference without changing accepted project identity.

Pitch decision fingerprints use a separate SHA-256 digest instead of reusing the state key, so
valid state keys also respect the narrower fingerprint limit. Agent tests now enforce the shared
platform operating-state rules, covering long model names, configuration changes, replay and
existing accepted-key compatibility.

Update Naomi through Installed Agents. No new capabilities, grants or configuration are required.
The platform source also adopts the shared SDK schemas/validation; this agent fix produces keys
compatible with the existing platform limits and does not require widening database columns.
