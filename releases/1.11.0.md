# 1.11.0

## Configurable creative-pitch token budgets

- Add installation settings for a 220,000-token context planning ceiling and a 32,000-token pitch output budget. The output budget includes model reasoning and remains subject to the selected provider's limit.
- Replace the fixed 2,048-token pitch cap with the configured output budget. The context setting keeps the configured output below the selected planning ceiling; it does not enlarge the model's actual context window.
- When the model returns no pitch text, direct the manager to the output setting and provider ceiling instead of reporting a generic timeout.
- No new capabilities, credentials, or network access are requested.

After deploying this version to an existing installation, retry the saved creative direction in Communications. The prior failed turns are not automatically replayed.
