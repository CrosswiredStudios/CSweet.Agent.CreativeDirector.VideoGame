# 4.1.4

Remove strict GDD heading validation and preserve independent semantic review.

- `GenerateDesignAsync` requests substantive design coverage in any clear structure.
  Different heading names, levels, order, prose and tables no longer trigger format
  correction. Complete drafts are submitted for the Director's independent semantic
  review; author generation does not certify acceptance.
- Only empty or output-limit responses trigger one corrective generation, with the
  approved pitch, prior GDD and exact Director feedback retained. Exhaustion creates
  no document/revision and reports a scoped typed generation-failure artifact.
- Durable generation receipts bind the assignment, session revision, package version
  and attempt. Duplicate delivery reuses results; an authorized resume permits a new pass.
- Shared GDD payloads and keys come from optional contracts 1.1.0; local request/result
  copies and heading-validation code are removed. Old request/result/feedback wire
  shapes remain readable, including additional document-reference metadata.
- Tests submit the original SHATTERCHORD heading-format excerpt unchanged and cover
  alternative structures, empty/truncated recovery, exact revision identity and replay.
- The existing resolved-review test fixture marks its resolved validation check
  passed, consistently with its resolved issue. Production-brief review policy is unchanged.

Publish contracts 1.1.0 first, then update Creative Director 4.1.4 with Director 0.6.9
through published releases and Installed Agents. No new grants or live retries are included.

Validation: all 49 Creative Director tests and 27 cross-role workflow tests pass.
The 4.1.4 self-test and pack pass with sibling SDK/work-contract/memory references
disabled and optional contracts 1.1.0 supplied as a NuGet artifact. Nuspec, bundled
manifest and dependency pin were inspected; the consumed contract DLL matches the
final contracts package byte for byte. No live provider evaluation was performed.
